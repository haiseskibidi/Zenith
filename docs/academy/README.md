# Zenith Academy: Практическое руководство по низкоуровневой разработке

Приветствую, коллега! 

Перед тобой **Zenith Academy** — фундаментальный интерактивный учебник по архитектуре игровых движков, низкоуровневой графике (OpenGL/LWJGL 3), физической математике, многопоточности и оптимизации JVM-памяти.

Этот курс написан на примере реального кода проекта **Zenith** — воксельной RPG с физически достоверной viewmodel-системой, гибридным GPU-Driven рендерингом чанков и высокопроизводительной сетевой архитектурой. 

Цель этого учебника — не просто задокументировать код, а **дать тебе глубокие, кристально понятные фундаментальные знания**, которые сделают тебя высококлассным специалистом. Изучив эти материалы, ты не только разберешься во всех тонкостях Zenith, но и сможешь с легкостью проходить собеседования уровня Middle+/Senior Java & Graphics Engineer, уверенно объясняя архитектурные решения "под капотом".

## Карта курса

Учебник разбит на 8 специализированных глав, каждая из которых лежит в этой же директории:

### 📦 [Глава 1. Управление памятью JVM & Стратегия Zero-Allocation](chapter_1_jvm_and_memory.md)
*   **Теория**: Heap vs Stack, CPU Caches (L1/L2/L3) и Data Locality. Как сборщики мусора (G1, ZGC) реагируют на частые аллокации.
*   **Практика**: Как писать код с нулевым выделением памяти (Zero-Allocation) в Hot Loops. Битовая упаковка данных (Bit-packing). Плоские массивы примитивов вместо сложных Java-объектов.
*   **Собеседование**: Вопросы про GC, утечки памяти, Escape Analysis и кэш-промахи (L1 Cache Miss).

### 🖥️ [Глава 2. Графический конвейер OpenGL & Системные вызовы](chapter_2_opengl_pipeline.md)
*   **Теория**: Как работает GPU и чем его архитектура отличается от CPU. Конвейер отрисовки: от вершинного шейдера до растрового кадра.
*   **Практика**: Низкоуровневая работа с OpenGL: VAO, VBO, EBO, UBO. Что такое Draw Calls Bottleneck и почему видеокарты "простаивают".
*   **Собеседование**: Вопросы про разницу между буферами, фазы рендеринга и профилирование графики.

### 🚀 [Глава 3. GPU-Driven Rendering & Оптимизация VRAM](chapter_3_gpu_driven_rendering.md)
*   **Теория**: Парадигма GPU-Driven рендеринга и перенос логики с CPU на GPU.
*   **Практика**: Архитектура **Mesh Pooling** в Zenith. Команды непрямой отрисовки (**MultiDraw Indirect**) через `glMultiDrawElementsIndirect`. std140 Uniform Buffer Objects. Алгоритмы Connected Textures и гладкого динамического света.
*   **Собеседование**: Вопросы про современные техники рендеринга, Indirect Draw и управление памятью на GPU.

### 📐 [Глава 4. Процедурная физика, Линейная алгебра & IK](chapter_4_procedural_physics_and_math.md)
*   **Теория**: Математика в трехмерном пространстве: векторы, матрицы, тригонометрия.
*   **Практика**: Симулятор пружины 2-го порядка (уравнение пружины-массы-демпфера, Euler Integration). Повороты костей скелета через Кватернионы (`Quaternionf` vs Euler angles). Математика PCA (Principal Component Analysis) для автоматической ориентации 2D текстур. Алгоритм инверсной кинематики FABRIK IK и Hinge-ограничения суставов.
*   **Собеседование**: Математические задачи на векторы, матрицы, кватернионы и интерполяцию (Lerp/Slerp).

### ⚡ [Глава 5. Реактивная шина событий & Архитектура ввода](chapter_5_event_driven_architecture.md)
*   **Теория**: Event-Driven Architecture и шаблон проектирования Publish-Subscribe.
*   **Практика**: Создание Zero-AllocInputAction слоя на плоских массивах. Потокобезопасная шина событий `EventBus` без аллокаций. Разделение ввода и логики через Decoupled Controllers. Логика `MiningController` с генерацией процедурных слабых точек (Weak Spots).
*   **Собеседование**: Паттерны проектирования, потокобезопасные шины событий, слабая связанность систем.

### 🎨 [Глава 6. Рендеринг интерфейсов & Шейдерная анимация шрифтов](chapter_6_ui_and_font_rendering.md)
*   **Теория**: Устройство UI систем, декларативная разметка и ортографическая проекция.
*   **Практика**: Аппаратное отсечение пикселей через `glScissor` при прокрутке списков. Шейдерные эффекты текста `FontRenderer`: Rainbow ($z$), Glow ($g$), Wave ($v$), Shake ($q$). JSON-верстка GUI и адаптивные фоны.
*   **Собеседование**: Особенности рендеринга UI, координатные сетки, scissor-тесты, работа с текстовыми атласами.

### 🧵 [Глава 7. Асинхронные вычисления & Многопоточность](chapter_7_concurrency_and_threading.md)
*   **Теория**: Модели многопоточности, гонки данных (Data Races), взаимные блокировки (Deadlocks).
*   **Практика**: Асинхронный конвейер чанков в Zenith, многопоточный расчет 3D освещения в `LightEngine`, защита палитры чанка от повреждений (`Palette Corruption Guard`), Lock-Free структуры данных и атомарные операции.
*   **Собеседование**: Тонкости `java.util.concurrent`, ключевые слова `volatile` и `synchronized`, модель памяти Java (JMM), Lock-Free паттерны.

### 🏆 [Глава 8. Шпаргалка для IT-собеседований (Senior Cheat Sheet)](chapter_8_interview_cheat_sheet.md)
*   **Практика**: Как правильно описать проект Zenith в резюме, чтобы удивить рекрутеров.
*   **Собеседование**: Топ-20 сложнейших технических вопросов с реальных собеседований на позиции Senior Java / Core Graphics Developer с подробными профессиональными ответами на основе кода нашего движка.

## Как эффективно учиться на этом курсе

1.  **Читай главу параллельно с кодом**: Открывай в своей IDE файлы классов, которые упоминаются в разделах "Практика".
2.  **Запускай дебаг**: Ставь точки останова (breakpoints) в методах `render()`, `update()`, `EventBus.post()` и смотри, как данные текут по системе.
3.  **Экспериментируй**: Изменяй параметры пружин в `physics.json`, добавляй свои эффекты в `ui_fragment.glsl`, пробуй сломать палитру чанка и смотри, как движок реагирует на ошибки.
4.  **Готовься к собесам**: Разделы "Собеседование" в каждой главе смоделированы по типу реальных технических интервью. Проговаривай ответы вслух — это закрепит понимание.

Желаю удачи в обучении! Давай сделаем твой технический уровень непревзойденным.
